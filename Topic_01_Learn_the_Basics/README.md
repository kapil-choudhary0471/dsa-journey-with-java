# 🧩 Problem-Solving Approach

For every problem, I try to:

1. Understand the problem
2. Identify the brute-force approach
3. Find an optimized approach
4. Implement the solution in Java
5. Analyze time complexity
6. Analyze space complexity
7. Test the solution
8. Document what I learned
